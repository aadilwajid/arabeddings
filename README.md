## 🌟 نظرة عامة

**ARA BEDDINGS** هي منصة تجارة إلكترونية متكاملة ومتقدمة لبيع منتجات الفراش الفاخرة في السوق الباكستاني. تم بناء المنصة باستخدام أحدث التقنيات مع التركيز على:

- 🎨 **تصميم حديث وجذاب** مع دعم كامل للوضع الداكن
- 🚀 **أداء عالي** مع تحسينات متقدمة
- 📱 **تصميم متجاوب** يعمل على جميع الأجهزة
- 🔒 **أمان متقدم** مع التحقق من المدخلات
- 📊 **لوحة تحكم شاملة** مع رسوم بيانية تفاعلية
- 🛠️ **خدمات خلفية متكاملة** جاهزة للإنتاج

### 📊 الخدمات الخلفية

#### 1. API Service
```typescript
import { api } from './services';

// Fetch products
const products = await api.products.getAll({ category: 'bed-sheets' });

// Add to cart
await api.cart.addToCart(productId, variantId, 2);

// Create order
const order = await api.orders.createOrder(orderData);
```

#### 2. Logger Service
```typescript
import { logger } from './services';

logger.info('User logged in', { userId: '123' });
logger.error('Payment failed', { orderId: '456' });
logger.success('Order created', { orderNumber: 'ARA-2024-001' });
```

#### 3. Cache Service
```typescript
import { cache } from './services';

cache.set('products', data, 60000); // 1 minute TTL
const products = cache.get('products');
```

#### 4. Analytics Service
```typescript
import { analytics } from './services';

analytics.trackProductView('123');
analytics.trackAddToCart('123', 'variant-1', 2);
analytics.trackPurchase('order-456', 15000, 3);
```

#### 5. Database Service
```typescript
import { database } from './services';

await database.connect();
const products = await database.find('products', { where: { category: 'bed-sheets' } });
```

#### 6. Notifications Service
```typescript
import { notifications } from './services';

await notifications.sendOrderConfirmation(email, orderNumber, total);
await notifications.sendOrderStatusUpdate(email, orderNumber, 'SHIPPED');
```

#### 7. Validators Service
```typescript
import { validators } from './services';

if (validators.isValidEmail('user@example.com')) {
  console.log('Valid email');
}

if (validators.isValidPhone('03211234567')) {
  console.log('Valid Pakistani phone');
}
```
